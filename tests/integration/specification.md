# テスト仕様案

App横断の依存は公開APIで検証する.

| ID                                | 種類       | ケース                                      | 期待結果                                                                   |
| --------------------------------- | ---------- | ------------------------------------------- | -------------------------------------------------------------------------- |
| <a id="tst-sys-01"></a>TST-SYS-01 | 単体・結合 | 同じLINEが2会員へ紐付く                     | 対象を切り替えてそれぞれ操作可能                                           |
| <a id="tst-sys-02"></a>TST-SYS-02 | 結合       | 退会済み・メイト会員の保護者                | 正・准会員への有効な紐付けで代理登録可能                                   |
| <a id="tst-sys-03"></a>TST-SYS-03 | 結合       | 無関係な会員の非公開詳細へAPI/RPCを直接送る | 非公開の参照・更新を拒否. 募集中の公開一覧は別の許可範囲で検証             |
| <a id="tst-sys-04"></a>TST-SYS-04 | 結合       | 権限剥奪・紐付け解除後の古いセッション      | 次の操作を拒否                                                             |
| <a id="tst-sys-05"></a>TST-SYS-05 | 結合       | 個人別出欠削除と集計保存                    | 取消を除外, 級別合計一致, 名簿・LINE紐付け保持                             |
| <a id="tst-sys-06"></a>TST-SYS-06 | 結合       | 集計化の再実行・途中失敗                    | 二重加算なし. バックアップ未処理なら完了扱いにしない                       |
| <a id="tst-sys-07"></a>TST-SYS-07 | 復元       | 期限前のバックアップを期限後に復元          | 個人別記録を公開せず期限を再適用, 集計を維持                               |
| <a id="tst-sys-08"></a>TST-SYS-08 | 結合       | 練習後の昇級                                | 練習時点の級を集計. 確定後の集計は変化しない                               |
| <a id="tst-sys-09"></a>TST-SYS-09 | 結合       | 休会者本人と正・准会員への代理操作          | 本人利用を拒否しても, 有効な別会員への代理操作は許可                       |
| <a id="tst-sys-10"></a>TST-SYS-10 | 単体・結合 | 退会者名簿3年・対象履歴1年の月初削除        | 年数未経過は保持, 経過後の月初に削除. 無関係な保護者アカウントを削除しない |
| <a id="tst-sys-11"></a>TST-SYS-11 | 結合       | ログ15日・実行記録90日・一時ファイル        | それぞれの期限で削除, 一時ファイルは処理後即時削除                         |
| <a id="tst-sys-12"></a>TST-SYS-12 | 復元       | 保存15日以内でも元データ期限超過            | 古い出欠を復活させない. 集計・基本属性の統合行を保持                       |
| <a id="tst-sys-13"></a>TST-SYS-13 | 結合       | 退会者名簿の最終削除                        | 対象の級履歴も削除. 確定済み練習集計と他会員の保護者アカウントを維持       |
| <a id="tst-sys-14"></a>TST-SYS-14 | 結合       | 毎月1日の共通処理の再実行・部分失敗         | 工程単位で再開でき, 二重集計・誤削除・成功の誤報告がない                   |
| <a id="tst-sys-15"></a>TST-SYS-15 | 結合       | 設定欠落・環境不一致・別環境のセッション    | 処理拒否. 本番設定への自動切替なし                                         |
| <a id="tst-sys-16"></a>TST-SYS-16 | 結合・運用 | 開発版の登録・削除・保存・復元・初期化      | 本番相当の隔離先に変更なし. 本番資格情報を開発側が保持しない               |
| <a id="tst-sys-17"></a>TST-SYS-17 | 結合       | 検証者許可解除・業務ロール剥奪              | 次の要求でそれぞれの許可範囲を失い, 古いセッションでも迂回不可             |
