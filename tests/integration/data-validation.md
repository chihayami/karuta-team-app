# データ辞書の検証仕様

列と入力規則が確定した後, 対応する所有Appの自動テストとして実装する. 新たな文字数・必須条件・値域は設計判断のレビュー対象. 各App・結合・E2Eテストの業務上の期待結果とは別に, 次の観点で確認する.

| ID                                | 検証対象                             | 期待結果                                                                                                                                                                               |
| --------------------------------- | ------------------------------------ | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| <a id="val-sys-01"></a>VAL-SYS-01 | 各列のNULL, 既定値, 必須入力         | 辞書と一致し, 未知の列・サーバー列の入力は拒否                                                                                                                                         |
| <a id="val-sys-02"></a>VAL-SYS-02 | 最小・最大長と境界外, 空白のみ       | 仕様の境界値を受理し範囲外を拒否. 切詰めなし                                                                                                                                           |
| <a id="val-sys-03"></a>VAL-SYS-03 | UUID, 日付, 時刻, 数値, コード, 配列 | 無効形式・未知コード・重複配列を拒否. 不明値を推測しない                                                                                                                               |
| <a id="val-sys-04"></a>VAL-SYS-04 | 姓名の片方, 多様な文字               | 決定した必須条件に従い, 文字種だけでは拒否しない                                                                                                                                       |
| <a id="val-sys-05"></a>VAL-SYS-05 | 遅刻早退の区分と値の組合せ           | 該当する型の列だけ必須. それ以外はNULL                                                                                                                                                 |
| <a id="val-sys-06"></a>VAL-SYS-06 | 級履歴とglobal.membersの原子性       | 一方が失敗したら両方未変更. 二重訂正・同日重複を拒否                                                                                                                                   |
| <a id="val-sys-07"></a>VAL-SYS-07 | 集計JSONと未確定NULL                 | 未知キー・負数・合計不一致を拒否. 確定0件と未確定を区別                                                                                                                                |
| <a id="val-sys-08"></a>VAL-SYS-08 | 所有者ごとのDBアクセス               | localとglobal双方で所有者以外の直接アクセスを拒否. 公開APIのみ利用可能                                                                                                                 |
| <a id="val-sys-09"></a>VAL-SYS-09 | 一括取込・バックアップ・復元         | 型, NULL, 先頭ゼロ, Unicodeを保持. エラー行があれば全件未確定                                                                                                                          |
| <a id="val-sys-10"></a>VAL-SYS-10 | 期限と監査・復元                     | 対象App内と保存先に期限適用. アカウント・会場単体の履歴は操作から1年経過後の月初, 練習・出欠操作は開催月N+2月1日に削除. 復元で期限超過履歴・失効セッションが復活しない                 |
| <a id="val-sys-11"></a>VAL-SYS-11 | 軽量な操作履歴の内容                 | 日時・操作者・対象・操作・changed_fieldsが一致. 許可された構造化列の変更前後のみchangesに保存. 氏名・備考変更は項目名だけで, 本文・秘密値・リクエスト全体・未知キーを保存しない        |
| <a id="val-sys-12"></a>VAL-SYS-12 | 業務更新と履歴の同時確定             | 成功時に対象ごと1件. 履歴書込または業務更新の失敗時は両方ロールバック. 拒否された操作・閲覧・画面遷移・通常ログイン成功に変更履歴を作らない                                            |
| <a id="val-sys-13"></a>VAL-SYS-13 | 履歴の対象と既存の運用処理           | 会場単体は練習IDなしで記録可能. 練習・出欠操作は対象練習ID必須. 期限削除・集計確定で削除対象の個人履歴を再作成せずoperation_runsへ件数・結果を残す. 業務上の級履歴は別の保持規則を維持 |
