# 設計判断

未決事項は対象AppのSQL・入力フォーム・対応テストの実装前に確定する. 後続Appの未決事項は初回リリースの着手・受入条件に含めない. 確定済みの判断も参照用にIDを維持する. 要件として確定している開発版の提供方式・受入条件は[環境仕様](development-environment.md)に記載する.

## データ辞書の入力規則

| ID | 判断 | 具体案 | 状態 |
| --- | --- | --- | --- |
| <a id="dec-rst-01"></a>DEC-RST-01 | 氏名・かなの必須条件と長さ | 姓名とかなはそれぞれ片方以上必須, 各100文字以内. 文字種制限なし | レビュー対象 |
| <a id="dec-rst-02"></a>DEC-RST-02 | 現役一覧の範囲 | ACTIVEを対象, 休会者は別の検索条件 | レビュー対象 |
| <a id="dec-sys-01"></a>DEC-SYS-01 | 各text列の上限・正規化 | データ辞書の長さ, 前後空白除去, 空文字のNULL化. 切詰めなし | レビュー対象 |
| <a id="dec-rst-03"></a>DEC-RST-03 | 会員コード・種別・級の移行対応 | 既存コードを保持, 新規M+年2桁+連番3桁. 欠損・重複・999超過はエラー | 移行サンプルと対応表が必要 |
| <a id="dec-rst-04"></a>DEC-RST-04 | 状態日付と級 | 新規状態変更は発効日必須, 過去不明はNULLで要確認. 同日昇級は当日有効, 予約昇級は初回対象外 | レビュー対象 |
| <a id="dec-prc-04"></a>DEC-PRC-04 | 時刻・値域・複合入力 | 日跨ぎ練習は初回対象外. 辞書の数値域と遅刻早退の区分別列を採用 | レビュー対象 |
| <a id="dec-ops-02"></a>DEC-OPS-02 | 保持期限の年単位境界 | 月初00:00に周年日を迎えたものを含める. うるう日の周年日扱いを確定する | 未決 |

これらは新しい入力制約を含むため, 既存の受付可否を黙って変更しない. [入力検証仕様](../tests/integration/data-validation.md)の境界値は判断後に確定する.

## 業務と運用

| ID | 判断する事項 |
| --- | --- |
| <a id="dec-aut-01"></a>DEC-AUT-01 | 初回自己申告の同姓同名表示項目, 管理者による変更確認手順 |
| <a id="dec-prc-01"></a>DEC-PRC-01 | 締切後の一覧と過去集計の閲覧範囲. 練習会設定班・全体管理者に限定する案 |
| <a id="dec-aut-02"></a>DEC-AUT-02 | 初期管理者の指定と検証方法. ロール付与数や上位ロール付与の制限は設けない |
| <a id="dec-prc-02"></a>DEC-PRC-02 | 休退会・メイト会員本人の取消条件, 中止後の操作, 未来の既存登録への担当者対応 |
| <a id="dec-prc-03"></a>DEC-PRC-03 | 集計の訂正権限と根拠. 初回は確定後閲覧のみとする案 |
| <a id="dec-ops-01"></a>DEC-OPS-01 | 月次実行時刻・許容遅延, バックアップ復旧時間・許容損失, 削除制御可能な保存先 |
| <a id="dec-env-01"></a>DEC-ENV-01 | 開発版検証者と外部設定値の指定. 提供方式の再承認は不要 |
| <a id="dec-ops-03"></a>DEC-OPS-03 | 同時実行数・応答時間, 移行範囲, 自動通知の採否 |

大会の入力単位・受渡し・締切境界・訂正・保存期間は[大会契約](../contracts/tournaments.md)と[大会業務ルール](../app/tournament-operations/docs/business-rules.md)に記載する. 大会2Appのデータ辞書はこれらの判断後, 実装前に確定する.

## 整合性レビューに伴う判断と適用範囲

| ID | 判断する事項 | 現時点の扱い |
| --- | --- | --- |
| <a id="dec-ops-04"></a>DEC-OPS-04 | 操作履歴の記録範囲と保持期限 | 確定. 問い合わせ時に参照する軽量な操作履歴とする. 日時・操作者・対象・操作・変更項目名と許可された構造化項目の値だけを記録. 専用画面・収集基盤・定期目視確認・通知は設けない. 列定義は[運用データ](operational-data.md), 期限は[保存期限](data-retention.md)を正本とする |
| <a id="dec-ops-05"></a>DEC-OPS-05 | ポータル独自テーブルの要否 | 確定. 初回は業務・監査・ジョブ実行のいずれも作成しない. globalの情報は認証App等の公開APIで取得し, 入口URL等は設定で管理する. 既存の各所有Appのoperation_runsは維持し, ポータル向けの運用DBを追加しない |
| <a id="dec-sys-02"></a>DEC-SYS-02 | 大会参加希望・大会班のテーブル名・列・保持期限 | 後続Appの実装開始時に確定. 未定義のまま初回4Appをリリースしてよい. [大会契約](../contracts/tournaments.md)と各Appのデータ辞書に従って確定後, 全体テーブル一覧と保持規則へ追加する. 初回の着手・受入を妨げない |

2026-10-09のレビュー承認により上記の扱いを確定した. 操作履歴の縮小に対応するテスト仕様の更新も承認済み. 年単位の期限境界等, 他の未決事項は引き続き個別に確定する.
