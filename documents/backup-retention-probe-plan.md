## 工程1の実装

1. `gas/backup/src/probe-retention.js` に実証用の期限判定を置く. 世代の保存日から15日を経過した場合と, 行に付けた明示的な期限が評価時刻以下の場合を判定する. 不正な時刻は拒否する. 実証は固定の評価時刻と架空の期限を使い, 実際の業務データやGoogleファイルの作成時刻から期限を推定しない.
2. `gas/backup/src/retention-probe.js` に引数なしの `runDevelopmentRetentionProbe` を追加する. development設定を検証し, 固定の架空データを新規ファイルに保存する. 既存の保存実証で作ったファイルも操作対象にしない.
3. まず15日以内の世代に, 期限到来した値と未到来の値を混在させる. 到来した値を除いた新しいSheetsファイルを作成し, 読戻して未到来の型・値・件数が一致することを検証する. 新しいファイルにも元のスナップショット日時と保存期限を引き継ぎ, ファイルを作り直したことを理由に15日の期限を延長しない.
4. 新保存物の検証成功後に, 期限対象を含む旧ファイル全体をDrive APIで永久削除する. 削除直前にファイルID・フォルダ・実証目的・development・今回の実行ID・削除権限を再検証する. この呼出し中に新規作成したIDだけを対象にする. フォルダや検索結果から削除対象を列挙する処理は追加しない.
5. 削除前の読取成功, 永久削除APIの正常終了, 削除後のHTTP 404を確認する. 一般的な例外, 401・403・5xxや404単独を削除成功の根拠にしない. 期限未到来の新保存物を削除後にもう一度読戻し, 値が保持されていることを確認する.
6. 別の新規ファイルで15日経過した世代を作り, 世代期限のため全体を永久削除する流れを確認する. 期限切れの世代を新ファイルへ移し替えて延命しない. ローカルテストでは15日直前・当日と, 元データ期限が先に来る場合の境界を検証する.

Google側には, 架空データを持つ新規ファイルを最大3つ作成し, そのうち旧世代と15日経過の実証用世代を永久削除する. 期限未到来の新保存物は確認用に残す. 実証が失敗した場合には途中ファイルが残る可能性を手順書へ明記し, 既存ファイルの一括整理や自動再試行は行わない.

保存形式は既存の実証用形式を利用し, 期限と世代の実証用メタデータを加える. 固定データの比較・不正入力拒否を維持する. 年単位の保持期限計算・実運用の月次ジョブ・全DBの業務モデルには適用しない.

## 外部通信と権限

- 既存のDrive・Spreadsheet scopeに `https://www.googleapis.com/auth/script.external_request` を追加する. UrlFetchAppを削除前後のHTTP状態確認に使用する. 運用者はコード同期後に追加のGoogle認可を確認する.
- 通信先は `https://www.googleapis.com/drive/v3/files/` と, 検証済みの新規作成IDから構築する固定URLのみ. 任意のURL・IDを受け取らず, リダイレクトを追わない. HTTPエラーの本文をログへ出さない.
- GoogleアクセストークンはScriptAppで実行時に取得してAuthorizationヘッダーにだけ使用し, 設定・ファイル・ログ・成功戻り値へ保存しない. 通信は回数を限定し, URL Fetchのタイムアウトを30秒に設定する.
- 成功ログは環境と検証した件数・削除結果だけとする. file ID・folder ID・データ全体・資格情報・内部例外は出さない. 現行の設定確認と保存実証の成功ログは変更しない.

GoogleのAPIを通じて管理可能なファイルの永久削除を確認する実証であり, Google内部の災害復旧コピーや運用者が別途作成した複製の消去まで証明しない. 複製・サービス管理の保管先と削除制御範囲は後続工程で記録する.

## 工程1の実装とローカル検証結果

- `runDevelopmentRetentionProbe` と実証用期限判定を追加した. 引数を拒否し, development設定の確認後に, 固定の評価時刻と明示的な行期限を使う. 年単位の業務期限や実運用スケジュールは確定していない.
- 同じ実行中に新規作成した最大3つのファイルのIDだけを内部で管理する. ファイル作成時・読戻し時・削除直前にフォルダ・実証目的・環境・実行ID・世代日時を確認し, 削除には所有者であることと削除権限も要求する. 既存ファイルの列挙・上書き・削除・共有設定変更は行わない.
- 元の3件のうち期限到来した1件を除き, 2件を新保存物へ保持する. 世代日時と15日の期限を引き継いで検証してから旧ファイルを永久削除する. 別の新規作成ファイルで15日到来の世代削除も検証する. 確認用に期限未到来の新保存物を1つ残す.
- 削除前のHTTP 200・永久削除APIの正常終了・削除後のHTTP 404を確認する. 404単独・401・403・5xx・一般例外を成功扱いせず, 部分失敗時に全体成功ログを出さない. 削除後も残すファイルの型・値を再確認する.
- UrlFetchAppのscopeをmanifestへ追加し, OAuthトークンを実行時に取得する. 固定のGoogle API URLだけへGETし, リダイレクトを追わず30秒のタイムアウトを指定する. レスポンス本文・ID・トークン・内部例外をログへ出さない. 利用者の実設定・Google認証情報とnpm依存は変更していない.

- `gas:check-files` が成功し, claspがmanifestと6つのソースだけを送信対象にすることを確認した. 新規の2ソースだけを明示的に許可し, 秘密値の架空サンプル・設定ファイル・テスト・未レビューのソースは除外される. 実Googleへの認証や更新は行っていない.
