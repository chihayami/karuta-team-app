# ポータルのテスト仕様

- <a id="tst-ptl-01"></a>TST-PTL-01: 利用可能な入口を表示し, 未設定のAppを表示しない.
- <a id="tst-ptl-02"></a>TST-PTL-02: 登録状況APIの障害時も他Appへの入口を利用可能.
- <a id="tst-ptl-03"></a>TST-PTL-03: 大会参加希望と大会班を別の入口として扱い, 班の権限を持たない利用者には班の入口を出さない案. API側の越権拒否も横断テストで検証する.

- <a id="tst-ptl-04"></a>TST-PTL-04: ポータル独自の業務・監査・ジョブ実行テーブルなしで表示・遷移が成立する. 入口URL等は設定, globalの情報は所有Appの公開APIから取得し, 直接DB参照や閲覧・遷移の操作履歴書込を行わない.

自動テストは未実装. 既存[ETE-SYS-05](../../../tests/e2e/specification.md#ete-sys-05)は横断E2Eに維持する.
