# App固有仕様

業務要件と具体的な設計案を記載する. 未確定の判断は「案」または「未決」と明示する.

## 名簿操作

- 会員コードは一意. 既存コードを保持し, 新規採番は同時作成でも重複しない方式にする.
- 入会・休会・復会・退会を履歴に残す. 会員種別と在籍状態を分ける案.
- 昇級は級履歴へ追加し, 現在級と最新昇級日を同時更新する.
- 過去日付の昇級や誤登録訂正を許可するが, 同じ会員の変更競合と履歴の整合性を検証する.
- 一括取込はプレビュー後に確定. エラー行があると全体を未反映とし, エラーを行番号で返す案.
- CSVからロール・LINE紐付けを変更できない. 未知の級・会員種別を自動変換しない.
- 名簿の変更申請はアプリ全体のスコープ外. 公式アカウント等の別チャンネルで申告し, 名簿管理者が変更する. 昇級専用担当の昇級登録は例外として維持することが仕様とする.
- 自動通知・自動メール送信は初回対象外案のままとする.
