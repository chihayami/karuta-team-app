# テスト仕様案

App横断の依存は公開APIで検証する.

| ID                                | 種類       | ケース                               | 期待結果                                                                                                                           |
| --------------------------------- | ---------- | ------------------------------------ | ---------------------------------------------------------------------------------------------------------------------------------- |
| <a id="tst-prc-01"></a>TST-PRC-01 | 結合       | 同じ出欠の新規登録を同時送信         | 行は1件. 内容が競合すれば通知                                                                                                      |
| <a id="tst-prc-02"></a>TST-PRC-02 | 結合       | 保護者2名による変更・取消競合        | 古いversionは拒否し, 保存済み更新を失わない                                                                                        |
| <a id="tst-prc-03"></a>TST-PRC-03 | 単体・結合 | 定員40に41人目を登録                 | ATTENDINGとして成功. 超過1を表示                                                                                                   |
| <a id="tst-prc-04"></a>TST-PRC-04 | 単体・結合 | 23:59:59と当日00:00                  | 前者は許可条件を満たせば成功, 後者は一般更新拒否                                                                                   |
| <a id="tst-prc-05"></a>TST-PRC-05 | 結合       | 締切後の担当者訂正                   | 権限・期限を満たせば成功. 操作者・対象・変更項目名と許可された構造化値だけを操作履歴に記録. 備考・訂正理由の本文は履歴へ複製しない |
| <a id="tst-prc-06"></a>TST-PRC-06 | 単体       | 1月1日・1月31日・12月31日の保持期限  | 1月分はすべて3月1日, 12月分は翌年2月1日                                                                                            |
| <a id="tst-prc-07"></a>TST-PRC-07 | 結合       | 遅刻・早退の両方を申告               | 各人数へ1ずつ, 登録総数には1だけ計上                                                                                               |
| <a id="tst-prc-08"></a>TST-PRC-08 | 規模       | 約300会員・練習1回80名・同日複数練習 | データ混同・重複・件数不整合なし. 応答時間基準は実証時に提案                                                                       |
| <a id="tst-prc-09"></a>TST-PRC-09 | 結合       | 募集中と締切後の参加者一覧           | 募集中は合意した全員へ開示. 氏名・級・遅刻早退・自由記述の備考を表示. 未ログインは拒否, 期間外は権限に従う                         |
| <a id="tst-prc-10"></a>TST-PRC-10 | 結合       | 時刻・試合数・自由記述の遅刻早退     | 時刻別/試合数別/OTHERの人数が一致. 原文・個人対応を集計へ保存しない                                                                |
| <a id="tst-prc-11"></a>TST-PRC-11 | 結合       | 練習基本属性・確定集計の統合         | 同じ練習行に保持し, 個人別削除後も消えない. 未確定NULLと0人の集計を区別                                                            |
