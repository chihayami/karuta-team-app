# テスト仕様案

App横断の依存は公開APIで検証する.

| ID | 種類 | ケース | 期待結果 |
| --- | --- | --- | --- |
| <a id="tst-aut-01"></a>TST-AUT-01 | 結合       | 同じアカウントで初回自己申告を同時確定        | 初回セットは1回だけ確定. 完了後の追加・変更を一般利用者へ許可しない |
| <a id="tst-aut-02"></a>TST-AUT-02 | 結合 | 管理者の確認済み印を変更 | 承認待ちを発生させず, 利用可否を切り替えない |
| <a id="tst-aut-03"></a>TST-AUT-03 | 結合 | 初回紐付け5名・6名と同時追加 | 5名は成功, 6名は拒否. 登録後は一般利用者の変更不可 |
| <a id="tst-aut-04"></a>TST-AUT-04 | 結合 | アクセス管理者のロール付与 | 上位ロールや付与数を理由に拒否しない. 付与権限のないアカウントは拒否 |
| <a id="tst-aut-05"></a>TST-AUT-05 | 結合 | 有効な紐付け・ロールがないアカウント | 月次処理でもアカウントと初回ロックを保持. 権限のない業務操作を拒否 |
