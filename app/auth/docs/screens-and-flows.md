# App固有仕様

業務要件と具体的な設計案を記載する. 未確定の判断は「案」または「未決」と明示する.

## 会員紐付けの流れ

初回は自己申告制, 登録後は本人変更不可. 管理者が紐付け状況を確認できる. 承認待ち状態は設けない.

具体案:

1. LINEログイン後, 本人・保護者として操作する会員と関係を申告する.
2. 初回に複数会員をまとめて指定し, 確認画面を経て一括確定する. これは出欠の家族一括登録とは別機能.
3. 紐付け作成とアカウントの初回登録完了を同時確定し, 直ちに利用可能にする.
4. 初回完了後は一般利用者による追加・変更・解除を停止し, アクセス管理者へ連絡する案.
5. 管理者は一覧で申告内容を事後確認する. 確認済み印は承認や利用開始条件にしない.

会員候補は名簿の名前検索で選ぶ. 1つのLINEアカウントに紐付け可能な会員は最大5名. 初回は1〜5名を指定する案とする. 同姓同名の識別に必要な補助項目は詳細設計で決定する. 未紐付けでも初回申告用の名前検索は認証後に利用可能とし, 名簿全項目の閲覧権限は与えない.
自己申告とロックは本人・代理資格の証明にはならないため, 誤紐付けを管理者が確認・修正できる構成とする. 招待コードは初回から除外する.
LINE変更は新アカウントを確認してから旧紐付けと旧セッションを失効させる. 他の保護者の紐付けは残す. 解除後も初回登録完了状態を自動解除しない.
