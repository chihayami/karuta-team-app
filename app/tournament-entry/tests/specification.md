# 大会参加希望Appのテスト観点案

- <a id="tst-ten-01"></a>TST-TEN-01: 許可された会員を対象に希望を保存し, 無関係な会員IDへの改ざんを拒否.
- <a id="tst-ten-02"></a>TST-TEN-02: 再送時に同じ希望を重複作成せず, 古い版による更新を検出.
- <a id="tst-ten-03"></a>TST-TEN-03: 保存・大会班への受領・参加確定を混同しない.
- <a id="tst-ten-04"></a>TST-TEN-04: 締切境界, 募集条件の変更, 通信失敗時の表示と再試行を検証.

自動テストは未実装. 代理範囲・締切ちょうどの期待結果等は契約レビューで確定する.
