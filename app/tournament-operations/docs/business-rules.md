# 大会業務ルール

大会関連機能は後続リリース対象. 以下は2026-10-08時点の合意事項と未決事項である.
詳細な業務条件は後続マイルストーンで確定する.

## 入金依頼・送金状態

要件:

- 後納大会の入金依頼タスクは初期値を対象外 `-` とする.
- 大会終了日に入金依頼対象へ遷移する.
- 主催者送金状態は, `送金依頼済` かつ日付経過の条件で `送金済` と判定する.
- 送金の実施は本プロジェクトのスコープ外とする.
- キャンセル繰上時の主催者送金状態は `未送金` とする.

未決:

- 後納の対象化時刻と, 対象化時のタスク値. `未` とする案.
- 送金判定の基準日付. 現行資料では入金〆を使用しているが, 会員入金締切と主催者送金締切を共用するか確認する.
- 希望者なし等で対象外のまま終了する大会の扱い.

設計上の注意: 後納の対象化前は入金依頼が `-` であるため, 「全タスクが済または対象外ならクローズ」の現行ルールをそのまま使うと早期クローズが起こり得る. 将来発生するタスクも含めた判定を設計する.

## 開催・締切

要件:

- 複数日程の大会は, 全日程が終了した時点で大会全体を開催済みとする.
- 会〆日の翌日朝7:00に受付を締め切り, 次の処理へ移る.
- 集計機能を追加したいという要望がある. 集計の詳細は未決.

例: 会〆日が10月8日なら, 締切は10月9日07:00となる.
タイムゾーンはAsia/Tokyoを提案. 締切時刻ちょうどの申込可否と, 大会最終日の終了時刻は未決.
練習出欠は別ルールとして前日24時に締め切る.

## 戦績・実出場・記録状態

要件:

- 結果入力が行われたことだけを理由に, 実出場フラグを一律TRUEにしない.
- 抽選落・キャンセル・当日欠席は実出場FALSEとする.
- 入力エラー欄は廃止する方向とする.
- 処理済みかどうかと, 正常に記録済みかどうかをチェックする.

未決:

- 大会前の実出場未確認をFALSEと同一視するか, 未確認状態を設けるか.
- 正常な戦績として必要な項目と, 抽選落・キャンセル・欠席を記録完了とする条件.
- 一部未入力や不正な戦績がある場合の大会全体の記録タスク判定.
- 既存入力エラー欄の移行時の扱い. 廃止を既存データの無条件削除とは扱わない.

## 年度別出場カウント

要件:

- 年度は4月から翌年3月までとする.
- 年度帰属日は現行どおり確定名簿配信日とする. 出場カウントは外部仕様であり, 厳格に従う.
- 例: 2026年3月31日配信・4月開催なら2025年度, 2026年4月1日配信なら2026年度に帰属する.
- 対象大会は公認大会, および主催大会のうち新春大会とする.
- 対象大会の確定名簿に記載されたことを出場カウントの根拠とする.
- 当日の実出場とは別の概念である.
- キャンセル理由を `名簿確定前`, `昇級`, `天候・交通`, `自己都合` の4種類に区別する.
- 昇級または天候・交通によるキャンセルはカウントから除外する.
- 自己都合キャンセルはカウントに含める.
- 昇級してもカウントをリセットしない. 年度が変わると新年度のカウントを開始する.

| 条件                                               | カウント |
| -------------------------------------------------- | -------- |
| 対象外の大会                                       | 対象外   |
| 確定名簿に未掲載                                   | 対象外   |
| 対象大会の確定名簿に掲載, 除外キャンセルなし       | 対象     |
| 対象大会の確定名簿に掲載後, 昇級でキャンセル       | 対象外   |
| 対象大会の確定名簿に掲載後, 天候・交通でキャンセル | 対象外   |
| 対象大会の確定名簿に掲載後, 自己都合でキャンセル   | 対象     |

設計提案:

- 過年度の実績は保持し, 年度指定で集計する. 年度末に過去レコードを消去したり加算フラグを一括解除したりしない.
- 確定名簿への掲載事実と現在の申込状態を別々に保持し, キャンセル後もカウントの根拠を辿れるようにする.
- 集計の再実行で二重加算しない構造にする.
- 新春大会の識別を名称の部分一致に依存させず, 業務設定で明示する.

未決:

- 延べ回数の単位が大会単位か日程・級別申込単位か.
- 繰上掲載や名簿再配信時にどの配信日を採用するか. 外部仕様を確認する.
- 当日欠席を4種類のキャンセル理由へ対応させる運用と, 理由不明時の扱い.
- キャンセル撤回や名簿訂正後の再判定.

## App間の境界

本書は大会班Appの業務ルール. 会〆等の募集条件は[大会連携契約](../../../contracts/tournaments.md)で一般会員向けAppへ提供する案. 参加希望の入力とは別Appとして管理する.
