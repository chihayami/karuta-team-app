# 大会班Appのテスト仕様案

## テスト観点

- <a id="tst-top-01"></a>TST-TOP-01: 自己都合キャンセルでも掲載済みなら対象となり, 昇級・天候交通では除外される.
- <a id="tst-top-02"></a>TST-TOP-02: 名簿確定前キャンセルや抽選落のみではカウントされない.
- <a id="tst-top-03"></a>TST-TOP-03: 会員の級を変更しても, 同年度のそれまでの対象実績は失われない.
- <a id="tst-top-04"></a>TST-TOP-04: 同じ確定名簿・戦績を複数回登録してもカウントが増えない.
- <a id="tst-top-05"></a>TST-TOP-05: 年度境界は確定名簿配信日の3月31日と4月1日で検証し, 開催日や昇級日に左右されないことを確認する.
- <a id="tst-top-06"></a>TST-TOP-06: 後納の対象化, 送金状態の更新, 会〆の遷移は再実行しても重複処理しない.
- <a id="tst-top-07"></a>TST-TOP-07: 送金依頼済以外のレコードは日付経過のみで送金済にしない.
- <a id="tst-top-08"></a>TST-TOP-08: 繰上確定直後は未送金であり, 自動的に送金依頼済にはしない.
- <a id="tst-top-09"></a>TST-TOP-09: 抽選落・キャンセル・当日欠席の結果登録で実出場TRUEにならない.
- <a id="tst-top-10"></a>TST-TOP-10: 複数日程の一部だけが終了しても, 大会全体を開催済みとしない.
